Examples:

| Domain                  | Description                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Availability            | **99.9% availability** for a corporate dashboard over a 30-day window (allowing about 43 minutes of downtime per month). |
| Availability            | **99.99% availability** for a critical infrastructure or DNS service over a quarter.                                     |
| Latency & Response Time | **99% of API requests** must return a response in **less than 200 milliseconds** over a 7-day rolling window.            |
| Latency & Response Time | **95% of e-commerce pages** must load completely in **less than 2 seconds** measured over a one-month period.            |
| Success and Error Rate  | Fewer than **0.1% of HTTP requests** may return 5xx errors (internal server errors) within a 24-hour period.             |
| Success and Error Rate  | **99% of login attempts** must complete successfully without system authentication failures over a 30-day window.        |
| User Experience         | **99.5% of video playback requests** must start playing in **less than 1 second** after clicking.                        |
| User Experience         | **98% of checkout transactions** in an online store must process successfully within 2 seconds.                          |
