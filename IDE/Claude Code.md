Is an IA tool from [[Anthropic inc]] that help programing  and manage source code, directly from terminal
- An assistent that runs com command terminal
	- An autonomous agent with ability to read files, run commands and fix errors by itself
	- Manage source code versions in [[Git]] 


## Plugins

Plugin hooks

SessionStart - Begining
PreToolUse - Before tool run
PostToolUse - After tool run
Notification - End

[[Ralph Loop]]
