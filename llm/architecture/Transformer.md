É uma arquitetura avançada de [[Deep Learning]]([[Rede Neural]]), composta por blocos empilháveis de dois componentes principais:
- layer 1 - [[Self-Attention]] - Linear, context
- layer 2 - [[Feed-Forward Network (FFN)]] - Parallel, key/value memory
- layer 3 - [[Positional Encoding]] reorder tokens, processed by second component
Is based on self-attention mechanism.
