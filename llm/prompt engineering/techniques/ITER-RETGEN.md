#technique #prompt-engineering #expansion #queryenrichment

Generate a prompt incomplete, loop over to fill the missing information.

1. Gere um rascunho com "missing markers"
2. Transforma lacunas (gaps) em buscas
3. Busca informações relevantes
4. Reescreve a resposta e verifica se há mais lacunas ou possibilidade de expansão

Draft -> Query -> Fill -> Expansion

**Example**
```text
A última versão da linguagem Python é [MISSING], sendo que Python foi criado por [MISSING]
```
