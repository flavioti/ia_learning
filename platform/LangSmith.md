A commercial tool built by the [[LangChain Inc]] team for debbuging, testing, evaluating, and monitoring AI applications and language models.

## Features
- tracing
- regression tests
- token cost evaluation
- latency monitoring

## Built-in tools
- LangSmith Fleet: A no code to manage agents
- LangServe: Deploy [[LangChain]] graphs as [[REST API]], ready to production, scalable and automatized.
- [[LangFlow]]: Visual workspace to draw [[Graphs]] ([[drag-and-drop]])
