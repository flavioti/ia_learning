#regression-metric 
## Definition
As [[MSE - Mean Squared Error]] changes the unit to square, it confuses humans, so the RMSE works in the same way, but bring back the result to readable number.

## Math notation
$$
\text{RMSE} = \sqrt{\frac{1}{n} \sum_{i=1}^{n} \left( y_i - \hat{y}_i \right)^2}
$$
