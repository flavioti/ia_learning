#model #foundational

Is a foundational model, open-source, developed by Google Research to [[time series forecasting]].
## Features
- [[Multivariate Forecasting]]
- [[Covariate Support]]
- [[Zero-Shot]] Performance

Available on Hugging Face as [[google!timesfm-3.0-pytorch]], and natively integrated into **[[Google Cloud BigQuery]] ML** via SQL commands like `AI.FORECAST`.
