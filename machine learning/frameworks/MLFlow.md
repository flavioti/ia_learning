#open-source 

Manage end-to-end [[ML - Machine Learning]] lifecycle and [[GenAI]]

- experiments tracking
- metrics tracking
- artifacts tracking
- model registry
	- model versioning
- model deployment (serve)
## Core components

**Tracking**: Parameters, metrics and artifacts
**Projects**: Virtual env to build and run
**Models**: train and inference (real-time or batch)
**Registry**: Governance of model lifecycle | Alias for (`Staging`, `Production`, `Archived`) and tags
